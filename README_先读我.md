# 卜了个卜 · JS 完整功能工程 v0.13

当前主入口是 `全模块游戏_双击打开.html`，微信开发者工具导入 `wechat_full/`。这一份包含全部源码、可重建网页、微信工程、独立账号后台和测试，不需要拼接旧包。

## 运行

安装 Node.js 22.13 或更高版本，无需安装运行依赖。

- `npm start`：先重建，再运行本机网页与开发服务，地址 `http://127.0.0.1:8770`
- `npm run build`：重建自包含 HTML 和微信工程；保留已有 AppID、项目设置与 preview-config.js
- `npm run online:serve`：启动独立账号后台，默认 `127.0.0.1:8771`，SQLite 保存在 `local-data/online.sqlite`
- `npm run full:check`：构建、全部测试与冻结源码校验
- `npm run online:test`：账号、后台、云同步和真实本地 HTTP 端到端测试
- `npm run full:stress`：混合命令压力与 270/540/720 张关卡通关重放

Windows 可使用原有 `启动全模块预览.cmd`。直接打开 HTML 时使用本机数据；HTTP 开发服务与微信在线接入是独立环境，不会假装数据已经跨环境同步。

## 微信配置

`wechat_full/preview-config.js` 支持三种明确模式：

- `simulation`：完整本机玩法，广告领取为明确标注的开发模拟
- `sdk_preview`：调用已配置的微信 SDK，业务身份仍是本机开发身份；没有模拟完成按钮
- `online_preview`：通过 `serviceUrl` 连接自家 HTTPS 后台，使用微信登录和账号云进度；登录或网络失败不会退回本地账号冒充成功

填写自己有权限的 AppID。真实 SDK 调用需相应广告位、能力开关及平台配置。AppSecret 只放服务端安全环境，绝不能进入客户端、版本库或分享文件。详细后端说明见 `services/online/README.md`。

分享返回不能确认消息已发送，真实 SDK 分享不发奖。广告 `isEnded` 也只是一条客户端观察：在线奖励只有独立可信服务端验证器授权后才应用。没有验证来源时按钮明确提示未配置，绝不由服务端给客户端声明“盖章”冒充验证。

## 真实边界

- 目前是可复跑的完整功能源码与本地联调工程，还不是可直接公开上线的微信成品
- 微信开发者工具、Android/iOS 手机、真实 AppID/广告位、真实 HTTPS 后台及审核发布尚未验收
- 270/540/720 张关卡是现有合成验收关卡；复活、社交周期、话题/皮肤等保留已披露的研究候选，不声称已找到原作全部历史规则
- 默认“广东队”是开发队伍，不读取或推断地理位置；朋友圈在非微信环境只展示本机/本人记录，不伪造好友
- 本地统计与受控接口测试不等于正式在线用户。排行榜只使用服务已接受的结果，不虚构人数；客户端用时未获独立可信验证，因此在线最快/无道具竞速荣誉保持关闭
- 原始旧文档、旧入口和 v0.12 压缩快照仅作历史记录；以本说明和当前源码为准

发布门禁仍关闭，`npm run full:release-gate` 应以退出码 2 列出未完成条件。接下来需自己的微信配置、后端安全环境、可信奖励验证来源、隐私/平台资格核查和两类手机实测；本包未购买、开通或部署任何云服务。
