# 首版平台与功能状态

独立 Godot 版本；v4 已验 Windows / Godot 4.7.2，本轮 0.3.0-character 在 Linux / Godot 4.6.3 验证，依据 JS PR2 精确提交 `362c61027b7a7f7e573f4b28608e3b3098e2092a`。玩法、存档和本地服务均在 GDScript 中运行。原 JS 目录保持只读，无推送、合并或发布。

| 原 HTTP / Node 宿主、完整生成器、浏览器旧进度迁移 | 不在此本地首版范围；不导入旧 token、ticket、奖励或 localStorage。 |

首版采用单进程本地 AtomicStore 的不可变 generation 与提交指针；坏的当前记录报错，不静默退回旧记录。未声称实现多进程写入、跨设备同步或断电级 fsync 保证。Canonical JSON 在源业务域和大量 IEEE-754 / UTF-16 排序向量中对齐；Godot 字符串无法保留的 NUL / 未配对代理字符不作为支持输入。

角色版验收及真实画面见 [character-v5-acceptance.md](character-v5-acceptance.md)。本轮保留原有视觉方向，未公开发布。
