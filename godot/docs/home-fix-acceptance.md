# 首页图标修复和功能核查

版本 0.3.1-homefix，基线 04ce140，2026-10-03。本页记录修复完成时的原始验收；当时仅独立 Godot 项目变更，原 JS 未修改。现已整理为独立 Godot 分支的公开源码副本，未合并 main；详见 source-publication.md。

## 已修复

1. 主页面 Button 的 StyleBoxFlat 默认按边框计算内容边距，只有 0–1px，导致 Phosphor 图标贴在圆角按钮左侧边缘。四个按钮状态现在使用 12px 左右内容边距；纯图标设置/返回按钮居中，命中区域保持原尺寸。
2. 本地弹幕此前在全部页面共用 y=124，覆盖社交页面副标题和对局进度条。现在主页、社交、对局各使用留白区；对局通知优先于弹幕显示。
3. 更新过时的角色占位说明、关于游戏中的错误游戏名。草帽/围巾、角色动效及玩法规则保持不变。
4. 源码导出预设不再引用不存在的旧绝对模板位置；使用编辑器当前版本的标准模板。Windows 交叉构建使用已校验的 Godot 4.6.3 匹配模板。

## 复跑

使用独立测试数据目录，避免污染玩家存档。Godot 4.6.3 的匹配平台模板可从官方发布获得。

```
godot --headless --path . --script tests/run.gd -- --suite all
GODOT_EXECUTABLE=/absolute/path/to/godot node --test tests/runner.test.mjs
godot --path . res://tools/home_feature_capture.tscn -- --qa-root=/absolute/new/test-output
godot --path . res://tools/home_scale_capture.tscn -- --output-dir=/absolute/scale-output
```

最后两个命令需要图形显示，不使用 `--headless`；所需新空目录须有写权限。GUI 驱动只发送鼠标事件，读取当前状态和开发验收序列，不直接注入胜利。旧 JS 导入/oracle 两个 Node 测试依赖原只读 JS 目录，本环境无该目录，未重跑这两个历史迁移工具测试。
