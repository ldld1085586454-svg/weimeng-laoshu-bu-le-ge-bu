## 上传范围

完整展开的 Godot 配置、场景、GDScript、UI、规则、会话、存储、本地服务、平台模拟适配器、测试与固定 oracle、开发工具、素材、字体和图标许可证、设计/迁移规范、验收说明及测试证据。开发快照的全部 269 个受版本管理文件均保留；仅公开整理 README、说明文档以及两个含开发机绝对路径的 JSON 元数据，运行时代码和素材不变。私人的附件定位符与开发机路径替换为说明占位符。

未上传 `.git` 历史、Godot `.godot` 导入缓存、临时目录、用户存档、凭据、引擎与导出模板，以及 Windows EXE/PCK、三卷分包和演示视频等大体积交付件。这些不是开发源码依赖；Windows 游戏包仍使用独立交付版本，需在 Godot 配置匹配平台模板后自行导出。没有用 ZIP 代替展开源码。

`PUBLIC_SOURCE_MANIFEST.json` 记录公开副本逐文件字节数、SHA-256 和 Git blob SHA-1（不包含清单自身），便于远端完整性比对。它不是数字签名。
