# Godot migration source provenance

Task 1 imports the reviewed source archive for commit `362c61027b7a7f7e573f4b28608e3b3098e2092a` into the independent Godot repository. The source archive is read only. Original JS modules are used solely by developer import/oracle tools; the Godot product consumes JSON and GDScript.

`data/source-manifest.json` records each imported resource's relative source path, output path, byte count, SHA256, commit, and origin. The importer resolves real paths (including existing ancestors/junctions) and rejects output equal to or beneath its source root. The Node guard tests hash every source file before and after both rejected invocations.

- `data/deals/`: original 270/540/720 deal JSON and private receipt witnesses copied byte for byte; tutorial exported from `src/product/catalog.js`.
- `data/catalog.json`: explicit `POLICY`, `REGIONS`, `SKINS`, `BULLETS` values. `profile.json` exports `PROFILE`; `limits.json` exports the integrated round's limits; `default-prefs.json` records the source defaults with motion enabled.
- `assets/theme/`: six active source atlases, their manifest, the complete user card index, original README, ZCOOL KuaiLe Regular TTF, and OFL license. The first fifteen T00–T14 cards and five reserves are unchanged. The unused `tiles.png` backup is excluded. Character/UI parts in the reference atlases remain source references pending the separate visual migration.
- `assets/audio/`: `click`, `clear`, `win`, `fail`, `music` WAVs generated by running the original `tools/build-full.js` inside a disposable independent source copy under the system temporary directory. The original build script's SHA256 and temporary build location are recorded. These are newly synthesized development tones, not original 2022 audio.
- `data/font-audit.json`: parses the bundled font's Unicode cmap formats 4/12 and checks all Han characters in source `ui/product/*.js`, catalog/social JS, and the new product title. The corpus is a superset of UI literals. All 417 unique characters are covered; no Noto fallback is required for this baseline.
- `tests/fixtures/oracle.json`: deterministic JS reference exports from the source's real `round`, `board`, `layout`, `catalog`, and `content-hash` modules. Includes complete deal blocker graphs, content hashes, canonical encoding vectors, and small command/state/event scenarios. This fixture is development evidence, not a runtime JS bridge.

No browser localStorage, `local-data/social.json`, authentication tokens, player tickets, or prior progress are imported. A future native service must start a separate local user/save namespace.

Reproduce from the repository root:

```powershell
node tools/import_source.mjs --source <read-only-source-root> --project .
node tools/export_oracle.mjs --source <read-only-source-root> --output tests/fixtures/oracle.json
$env:MIGRATION_SOURCE = '<read-only-source-root>'
node --test tests/*.test.mjs
$env:APPDATA = Join-Path $env:TEMP 'godot-task1-appdata'
& <godot-console.exe> --headless --path . --script tests/run.gd
```

The Godot executable used for verification reports `4.7.2.stable.official.ed1daf0bf`. This sandbox prevents reading the Windows root certificate store, so Godot prints that environment diagnostic on startup; the offline rules tests require no certificates or network.
