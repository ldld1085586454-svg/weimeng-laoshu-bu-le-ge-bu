# 商业化接入与模块任务 v0.10

**既有基线：** `src/*.js` 为用户认可算法，`src/play/*.js` 为v0.9对局模块。本包两组均未更改。商业模型 `src/commerce/model.js` 只验证业务协议，不调用平台、不替代数据库、不承担真实广告验真。

## 一、当前已交付

- 商业规格与数据口径。
- 四业务触点配置；生产开关、分享领奖关闭；复活未绑定。
- 不可变状态流程模型：资格预检、完成证据、待兑现、已作用、继续、重复事件和错误恢复。
- 收入报表算术：预估/结算/到账分开、缺失与0分开、净收入不再次分成。
- 单文件交互演示，使用同一模型；其中每一个广告结果由明确的模拟按钮产生。
- 28项新增模型测试；全部测试结果以reports中最终重跑记录为准。

## 二、D01 领取与真实SDK适配（完整模块，不拆零碎口头任务）

输入：v0.9 Session/Board预检查、commerce配置、可用AppID/adUnitId、用户主动确认。

输出：实际sdk-adapter（尚未实现）与统一结果类型：completed_client_evidence / incomplete / unavailable / error / unresolved。不要造一个share_success事件。

要求：
1. 预检查在展示之前；一个流程只持有一个广告实例/匹配回调；监听注册、注销使用同一个函数引用，不能删除其他实例的监听。
2. load成功不发奖，show成功只记客户端展示；onClose明确true才进入权益处理。不同广告单元和旧局回调必须区分。
3. 生命周期后台/前台不作为分享或广告完成证明。加载超时可以失败回退，正在展示后的缺回调必须保留未决，不自动发奖或静默丢弃。
4. 无库存/被限流/错误使用已核验的SDK错误含义；不依赖网页上未经验证的错误码猜平台额度。
5. 不预设30秒；不拦SDK关闭；不自动重复播；必要重试要求一次新的明确用户操作。
6. 需要核查 `disableFallbackSharePage` 支持版本及组件行为；现有类型字段不是已完成真机支持验证。

交付：源码、接口桩测试、取消/早退/加载失败/重复回调/跨局回调/前后台测试、真机录像及日志。SDK桩通过不能写真机通过。

## 三、D02 权益与我方后端事务

输入：prepareOffer（roundId、boardRevision、placementId、规则版本）、SDK观察结果（来源标记）、我方已验证会话。

输出：claimId及明确状态、原局作用结果、计数变化、可重试回执。

推荐接口（我方设计，非微信已有API）：
- POST /commerce/offers：验证局面可作用并预留资格；返回一次性attemptId、原局版本和已固定配置。
- POST /commerce/claims/{id}/evidence：幂等接收证据及来源；客户端字段不当作不可伪造证明。
- POST /commerce/claims/{id}/apply：在原局和版本上提交作用与次数。使用数据库唯一键和事务。
- GET /commerce/claims/{id}：恢复等待状态；完成观看后失败重试不要求再看广告。

唯一约束：attemptId、claimId、(roundId,placementId,allowedUseOrdinal)；具体SQL/云数据库实现待选择后落地。不是在本地Map里记过一次就称跨设备恰好一次。

重要：v0.9 createSession 只允许 development_mock。不得简单把生产回调传给它再声称生产可信。真实模式必须另建受控边界和状态恢复协议；旧mock仍留给测试，并从生产入口去除。

复活绑定（U）：必须补齐作用与额度/暂存关系。禁止用未绑定的复活收集真实广告展示。

## 四、D03 结果、地区和原有展示

输入：我方验证通过的通关记录；原作模式/地区/话题/荣誉规则档案。

输出：结算回执、已确认贡献与展示数据。网络失败有明确待同步状态，不伪造排名人数；相同round重交不重复记分。侧边好友展示按开放数据域实际权限接入，不取代为我方自造好友。

接口建议：POST /rounds/{id}/result、GET /results/{id}、GET /leaderboards?scope=...。列名与加分规则按证据绑定；这些路径不是原作私有接口。不访问原作私服身份或服务。

## 五、D04 经营数据与报表

输入：行为事件、权益事件、平台报表、实际推广/可变成本。

输出：口径明确的漏斗、未兑现清单、每日平台差异、成熟队列留存和收入/成本对照。

要求：匿名标识、隐私最小化、来源白名单、eventId去重、报表版本化、币种/时区固定、缺失不变0、共享广告单元不声称精确分道具收入。

交付：采集与去重测试、金额单位校验、跨日示例、迟到报表修订、多广告单元映射、样本与真实数据隔离。模拟100次广告不得向真实平台发100次请求。

## 六、复核顺序与停止条件

D01与D02合同先共同确认，然后可并行实现；D03/D04按相同编号关联。算法继续冻结，不为商业化改底牌。

复核者拿到主规格+本轮源码+v0.9基线，不以之前声称通过的数量代替重新运行。

必须拦截：无明确观看资格即拉广告；已完成但丢权益；旧局误发新局；重复作用；假分享成功；客户端播放计现金；复活未绑定却开放；共享广告单元收入被误拆；生产包含模拟完成按钮。

发布清单 `config/release-checklist.json` 初始全部未验收。清单中“未完成”是明确阻断项，不是让执行模型自行编造具体原作规则。
