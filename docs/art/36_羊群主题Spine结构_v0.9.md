本轮把此前只关注 `Sheeps / Dead1 / Finish1` 扩展为完整的可见羊群动画资源族。

- `sheep/BG`：Stage1 / Stage2
- `sheep/DJ1`：主题皮肤 `00 / The01 / The02 / The03`，动画 Jump2 / Stage0 / Stage1
- `sheep/UI`：手势、草、射线等界面动画 `1Hand1 / 2Grass / 2Grass2 / 3Ray1 / 4Ray1 / 4Ray2`
- `sheep/Theme`：主题阵亡表现与旗帜/聚光灯
- `Sheeps`：34 个基础 skin（skin_00..33）
- `ThemeSheeps`：14 个主题阵营 skin（The01A..The07B）
- `Dead1`：11 级失败/墓碑动画
- `Finish1`：3 个通关动画 + Run

完整索引见 `community_index/sheep_spine_catalog_v09.csv`。
