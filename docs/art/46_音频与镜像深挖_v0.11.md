# 音频与镜像深挖 v0.11

本轮检查了 qierkang 全部 10 个 2022-09-15 commit、普通 forks、多个独立镜像、真实微信 1.2.4 缓存。

结论：此前 18 个缺失原生 MP3 **仍未找到可信原件**。它们不是 qierkang 后续 commit 删除，而是从最初公开提交起就没有上传。

部分二创仓库虽然保留相同 UUID 文件名，但 SHA/大小与已知原始音频不一致，不能当原件使用。`oldyue/chicken` 额外保留了 moveOut 的 import metadata，但没有原始 native `bc433.mp3`。

`matrix3d/a-sheep` 的 cacheList 证明 1.2.4 的官方静态资源根路径为 `cat-match-static.easygame2021.com/catMatch/sheep_wx_1_2_4/`，但该捕获会话只下载了部分音频；“未出现在 cacheList”只能表示该会话未加载，不能证明 CDN 不存在。
