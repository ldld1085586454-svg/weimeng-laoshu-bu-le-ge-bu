# 首页 / 社交 / 弹窗结构 v0.9

主 UI 包可直接确认的模块包括：

- 今日话题 PK：阵营选择、已加入、昨日胜方、今日新话题、进度条、红蓝标题、VS。
- 今日朋友圈：今日排名弹窗。
- 好友历史排行：独立 `FriendRankPop` / `FriendSubContextView`。
- 个人资料：昵称、注册信息、每日通关/话题次数、失败次数、羊名、头像。
- 换装：前后翻页、页码、确定、羊展示、装扮列表。
- 弹幕：发送按钮、弹幕图标、弹幕弹窗。
- 设置：音乐、声音、震动、弹幕开关、返回羊群。
- 失败 / 通关 / 复活 / 分享 / 排名 / 阶段荣誉。

对应源符号见 `community_index/main_popup_symbols_v09.csv`。

这使 v0.12 后续 UI 还原可以按真实模块边界开发，而不是自行发明菜单结构。
