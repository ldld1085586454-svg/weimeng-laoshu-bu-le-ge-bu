# 微信 1.2.4 与 H5/社区 1.2.8 差异

## 换装
两版客户端配置均有 48 个 clothesId，spName/spSkin 编号结构一致，但大量**显示名称发生变化**。例如：

- ID2：1.2.4「卷羊」→ 1.2.8「口罩羊」
- ID7：1.2.4「乌龟羊」→ 1.2.8「拉斐尔」
- ID8/9：1.2.4「文羊/武羊」→ 1.2.8「僵尸羊/道士羊」
- ID14：1.2.4「西瓜羊」→ 1.2.8「练习生」

这证明骨骼皮肤槽和显示命名是两层；不能用后期名字倒推首周名字。完整差异见 `clothes_names_124_vs_128_v011.csv`。

## 主 UI
1.2.4 被该缓存实际抓到的 main import 含 66 个 SpriteFrame；1.2.8 对应 import 有 134 个。66 个名字全部能在 1.2.8 找到，但有 43 个发生图集坐标/旋转变化。1.2.8 还多出 68 个 frame。

1.2.4 已明确出现 `topicChoosePop`、`topicJoinedPop`、`TodayRankPop`、`FriendRankPop`、`PersonalPop`、`BulletScreen`、`今日朋友圈`、`历史排行榜`、`好友历史排行榜`、`换装` 等符号，说明这些系统至少在 1.2.4 客户端结构里已经存在。
