# 双仓 2022 快照交叉验证 v0.8

## 目的
不把单一社区仓库当成“官方原件”。本轮增加第二个 2022-09-16 快照，与此前 2022-09-15 的 `qierkang/yang-game` 进行交叉验证。

## 两个快照
- `qierkang/yang-game`：commit `11fe37888add6f44f688f798ede3c6fd612eedc5`，提交时间 2022-09-15T13:55:24Z。
- `bkkkker/yxj`：commit `bd57224f372ca7809d80c57305f35cf27eb631e7`，提交时间 2022-09-16T10:28:41Z；相同构建位于 `test/` 下。

## 结果
1. 两份 `resources/config.8b75c.json` 的 Git blob SHA 不同，因为格式化方式不同；解析 JSON 后做稳定排序序列化，**语义内容一致**，`paths / uuids / versions` 均一致。
2. 两仓共有 22 个 `assets/resources/native/*` 二进制文件路径；其中 **21 个 Git blob SHA 完全一致**。
3. 唯一不同的是 `assets/resources/native/46/46043294-9105-48ab-a8f5-bca2849212fd.51dee.png`，对应 `sheep/BG` 背景纹理。
4. 卡牌图集、rewardIcon 图集、rank 图集、基础羊、主题羊、Dead1、Finish1 等关键纹理在两个快照中 Git blob SHA 一致。

## 能说明什么
- 这些关键资源并非只在单一仓库偶然出现，至少存在两个相邻日期的社区快照互相印证。
- 这提高“资源结构确实来自同一类 2022 构建”的可信度。

## 不能说明什么
- 不能证明仓库由北京简游科技官方发布。
- 不能证明每个资源当时都已向玩家开放。
- 不能仅凭社区构建许可证推导原始游戏美术的商业授权。
