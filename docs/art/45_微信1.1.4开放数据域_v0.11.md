# 微信 1.1.4 开放数据域 v0.11

2022-09-16 的微信包包含 `wx-open-data-project`，可直接确认好友榜/朋友圈不是 H5 社区后加的假入口。

- 好友历史榜 key：`friendRank`
- 今日朋友圈 key：`todayRank`
- 读取：`wx.getFriendCloudStorage`
- 写入：`wx.setUserCloudStorage`
- 榜单长度参数：200
- 今日朋友圈仅纳入 `moonCount > 0` 且更新时间为当天的好友。
- state 为 `win` 时显示正常羊；否则按失败次数分 Dead1~Dead8 墓碑/死亡形象。

失败次数阈值在该开放数据域代码中为：<10 / <20 / <40 / <60 / <100 / <140 / <180 / 其余，对应 Dead1~Dead8。
