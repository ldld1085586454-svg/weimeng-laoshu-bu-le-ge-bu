# 音频文件存在性与接入边界 v0.8

社区 `resources/config` 声明 26 个音频资源键，但 Git 仓库树实际保留的 native MP3 只有 8 个。

目前确认存在的 8 个为：
- `clickBlock`
- `blockRandom`
- `game_cycle`
- `main_music`
- `levelInit`
- `game_begin`
- `crush`
- `transitFont`

其余 18 个仍只属于“配置声明”，不能写成“原音频已找到”。

完整状态见 `community_index/audio_native_presence_v08.csv`。

即使某个 MP3 出现在社区仓库中，也只证明社区快照包含该字节；正式发布前仍需独立确认音乐/音效的版权授权范围。
