# v0.12 真实资源落位说明 v0.5

## 当前 v0.12 的实际情况
`wechat_full/ui/product/art.js` 仍然使用程序绘制的开发矢量图，因此“复制图片进目录”不会自动改变画面。

本包现在补齐了两个层次：

1. `dropin/v0.12_runtime/`：标准资源目录契约，供浏览器 / 后续构建使用。
2. `dropin/v0.12_wechat/`：精确对应 `sheep_full_v0_12/wechat_full/assets/art/` 的微信小游戏路径，并附 `src/product/art-assets.js` 路径适配器。

## 接入原则
后续开发只需把 `art.js` 中的 `symbol()/sheep()/tomb()/grass()` 绘制调用逐步替换为图片渲染，游戏算法和牌局状态机不需要改。

## 重要边界
- 当前 PNG 是开发占位资源。
- 历史截图只用于视觉还原参考。
- 社区构建索引用于定位 / 提取，不等于官方授权原素材。
