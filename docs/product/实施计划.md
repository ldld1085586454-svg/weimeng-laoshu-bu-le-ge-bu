# v0.12 全模块实施计划

目标：沿用已认可 v0.8 算法与最后 v0.11 的全部旧源文件，将 P01—P16 接成可玩的原生 Canvas 开发复现工程。
架构：原内核保持不变；新 product 命名空间合入另一份 v0.11 已交付的候选复活，界面只派发语义事件；同一业务服务支持浏览器本地与 Node HTTP 开发服务器；微信入口另行打包。
技术：JavaScript CommonJS、Canvas 2D、Node 22 内置测试与 HTTP、微信原生接口。无额外运行依赖。
授权：用户已要求“模块全做好”，不另起玩法设计评审；历史不明处保留候选状态。

硬约束：只做 2022 目标范围；不增加充值、金币、体力、商城、Banner、插屏、强制分享、提示答案。原版素材/完整历史规则未取得，不写成已还原。所有运行配置默认 development，不允许绕过发布门禁。
