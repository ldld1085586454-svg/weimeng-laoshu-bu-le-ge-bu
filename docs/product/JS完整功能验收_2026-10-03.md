# JS v0.13 完整功能与验收

本版在原 JS 分支 362c610 基础上独立完成，没有改动 main、Godot 分支或发布到公共服务。

## 完成内容

- 原有全部玩家页面及玩法继续接通，修复退出失败后的计时、话题贡献文案、跨日输入、销毁后的迟到请求和旧局回调
- 原始萝卜素材与 20 个 Phosphor Bold 图标同步至 JS；保留原牌面、背景、字体和声音。角色包含呼吸、眨眼、叶摆、点击、消除、胜负、复活表现，减少动效立即静止
- 首页继续/重开，同账号当日原 ticket 恢复；离线时间不计，首次失败保留复活选择。已赚取奖励与结算 outbox 优先恢复
- 独立 Node/SQLite 服务实现微信 code 交换适配、会话、云进度 CAS、奖励账本、结算幂等和分页榜单
- 微信 `online_preview` 显式传入网络客户端；失败不冒充本地登录，账号改变会锁定旧实例，旧存档不能写入新账号空间
- 云冲突须明确选择；保留本机使用专门 CAS 决议接口，备份原记录、关闭旧局。包含不同奖励记录的同局分叉不能合并，只能选云端或确认放弃重开
- 原生分享回流不发奖，按钮明确标注“不发奖”；真实广告完成观察须经过独立服务端授权。缺验证器时真实奖励关闭。已保存的核验失败可重试原笔，不重复播放广告

## 本轮实际验证

- `npm run full:check`：560 项通过，0 失败，0 跳过
- 冻结源码：12 个算法文件、包含它们的 20 个旧源文件哈希均不变
- `npm run full:stress`：100 轮混合压力、5738 条命令；270/540/720 张关卡分别完整通关并保存重放。混合压力主动制造失败，不是玩家通关率
- 后台 HTTP：账号/会话隔离、SQLite 重启、CAS、伪造奖励拒绝、grant 归属/过期/幂等、事务回滚、旧验证取消、明确冲突决议均有自动测试
- 真实本机 HTTP 端到端：换设备续同一 ticket 并结算；独立测试验证器授权的奖励云保存/恢复；不同局与纯取牌分叉的本机选择；奖励分叉转云端恢复，并验证选择后新步数继续上传
- 独立代码审查发现的四项身份/奖励/冲突竞态已修复并复验；原有 AppID 和 preview 配置保留测试通过
- 额外运行无 `Object.hasOwn` / `Array.at` 的受限 JavaScript 环境，新增角色、图标与同步队列通过兼容回归
- 原生 Canvas 实际渲染并驱动指针流程：12 张教学、270 张每日通关、取消触摸、返回续局、撤回、角色动效。取得 11 张实际运行画面，覆盖 320×568、390×844、430×932、1280×900

画面来自 Node 原生 Canvas 执行同一份游戏代码，不是设计效果图，也不是本轮浏览器、微信工具或手机截图。原生绘图验收宿主每 12 次输入重置绘图表面以限制其保留缓存；不重置游戏状态、时钟或命中区，因此不作为设备内存/性能验收。

日志与画面：`verification/2026-10-03/`。可选取图脚本为 `tools/native-render-qa.js`，需要已安装的 `@napi-rs/canvas`，用 `BU_CANVAS_MODULE` 指向该模块并以 `node --expose-gc` 运行。核心游戏、构建、后台和自动测试不依赖这一取图模块。

## 尚未真实验收的接入条件

1. 自己有权限的小游戏 AppID、广告位与平台开关
2. 自家 HTTPS 服务、微信合法域名及服务端安全环境配置；AppSecret 不得进入客户端或代码库
3. 独立可信奖励验证来源。当前查阅到的官方公开接口只有客户端 `onClose/isEnded` 观察；没有取得可用于本项目的服务端验签凭证，不能自行假造一个
4. 微信开发者工具与 Android/iOS 手机全流程、前后台/弱网/音频/存档/广告及好友域检查
5. 隐私与平台资格、最终发布素材及候选规则确认、真实部署运维和审核

未购买、开通或公开部署任何服务；真实平台登录、广告和手机均未验收。`npm run full:release-gate` 仍以退出码 2 封闭发布。源码与本地联调完成，不等于微信已经上线。

官方能力核对入口：[微信类型定义](https://github.com/wechat-miniprogram/minigame-api-typings/blob/master/types/wx/lib.wx.api.d.ts)、[官方激励视频示例](https://github.com/wechat-miniprogram/minigame-demo/blob/master/miniprogram/js/api/AD/createRewardedVideoAd/index.js)。接口适配不代表账号后台额外资格或最新审核要求已核实。
