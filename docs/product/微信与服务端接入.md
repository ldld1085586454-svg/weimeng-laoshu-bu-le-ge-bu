# v0.12 微信、数据与服务端接入

## 一、默认行为

| 宿主 | 主入口 | 业务数据 | 领取 | 排行与游戏圈 |
|---|---|---|---|---|
| 自包含HTML | 全模块游戏_双击打开.html | localStorage，受限时仅内存 | 明确标注的模拟回调 | 本机统计；好友/游戏圈提示平台边界 |
| 本机 HTTP | 启动全模块预览.cmd | Node服务 JSON 文件 | 同样是开发模拟 | 同一服务多个开发身份共享统计 |
| 微信 simulation | wechat_full/game.js | wx本机存储中的开发服务 | 明确标注的模拟回调 | nativeSocial默认关闭 |
| 微信 sdk_preview | 同上 | 同上，不是生产认证 | 仅由平台接口产生回调；无模拟完成按钮 | 开启nativeSocial后调用平台接口 |

没有原作账号、原作API、第三方凭证或真实广告位ID。本版不上传你现有的私人数据。

## 二、微信参数

配置 `wechat_full/preview-config.js`：

```js
module.exports = {
  mode: 'simulation',       // 或 sdk_preview；不接受 production
  nativeSocial: false,
  allowSharePreview: false,
  allowAdPreview: false,
  adUnitId: '',             // 仅填写自己的广告位
  shareTitle: '每日三消挑战',
  rewardRoute: 'video'      // 或 share：开发配置，不是新增玩家选路玩法
};
```

构建会保留已经存在的这一配置文件，不覆盖你填写的预览参数。首次交付的默认值已通过测试；打开原生接口后不要再把“默认值保持关闭”的回归断言当作配置验收。

AppID填在开发者工具的项目配置，**AppSecret不得放入客户端**。本包没有实现生产 `wx.login -> 服务端校验 -> 生产会话`；不能把本地开发身份替代真实微信账号认证。

代码对 `getWindowInfo` / `getSystemInfoSync`、安全区与菜单矩形作能力检测；Canvas绘制坐标、触摸坐标和原生游戏圈按钮坐标使用同一偏移。短屏会缩放内容而不是让按钮重叠。具体基础库和设备表现仍以实际微信测试为准。

原生广告只在明确 `isEnded === true` 时产生完成观察，结果未知不发奖。分享只记录先离开再返回的观察，**不证明用户发送成功**。旧局的回调不会兑现到新局；已经显示的广告不能由本适配器强行关闭，其旧监听会隔离到返回结束。

好友分数使用本项目自己的 `sheep_dev_today` 与 `sheep_dev_history` 键。`open-data/renderer.js` 在开放数据域读取并绘制好友记录，主域只发显示指令、接收共享画布，不接收好友名单。显示的是开发项目成绩，不是原作成绩。没有把自己构造的用户列表冒充微信好友。

## 三、本机服务契约

Node.js 22及以上，无第三方运行依赖。`node services/server.js` 或 `npm run full:serve`。默认仅监听127.0.0.1，`PORT`可修改端口。Host/Origin不匹配、无会话、错误JSON、超大请求、任意文件访问被拒绝。

`POST /api/login` 接收 `{deviceId: "browser-..."}`，返回开发会话token。它只是**开发身份**，deviceId可以被拥有机器的人复制；不具备生产认证可信度。

`POST /api/call` 携带 `Authorization: Bearer <token>`，请求 `{action, data}`。userId从开发会话取得，不从提交结果里采信。

| action | 主要输入 | 返回/校验 |
|---|---|---|
| bootstrap | 空 | 当前日、档案、地区、话题、荣誉、换装、历史、弹幕 |
| start | mode: tutorial / daily / topic | 当前日ticket与发放关卡 |
| settle | ticketId、log、elapsedMs | 重放日志、核对发放快照、归属、终局、时长与日期；同笔幂等 |
| equip | skin | 已解锁检查；不改变游戏属性 |
| bullet | id | 只允许预设内容 |

当前算法可阻止没有完成关卡却直接提交“成功”的简单伪造，以及使用另一份简单地图冒领指定关卡成绩；**不等于完整生产反作弊**。当前客户端观察可以被开发者伪造、计时也不是服务端独立测得，正式部署必须用真实认证、服务端奖励凭证和独立反作弊约束。

数据库是开发用JSON文件，临时文件写入后重命名。只考虑单进程写入，未实现分布式锁、生产数据库事务、审计备份、限流/监控或公开服务部署。不把本机服务的通过测试写成生产后端完成。

## 四、研究候选与未核实项

复活：主槽前三张追加暂存，保留已有暂存，最大六张；其实现来自此前交付候选，不是官方证实的2022边界。暂存任取、三消后撤回失效、每日北京时间零点、首次本地教学、同日同模式去重、话题分组/昨日奖励/荣誉并列规则都按已披露开发候选执行。

话题文案“早起派与夜猫派”、三款形象和解锁方式是开发替代数据，不声称是2022的真实题目、完整皮肤名单或实际奖励配置。
