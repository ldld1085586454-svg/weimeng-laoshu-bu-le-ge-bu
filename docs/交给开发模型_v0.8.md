# 接手说明：先复验当前基线，再接完整游戏

当前可运行源码唯一入口为根目录 `src/`，微信联调目录为 `wechat_probe/`。
目标：2022 年爆火时期微信《羊了个羊》的玩法和商业流程还原。允许用自研替代隐藏算法，不准把新增玩法或社区改动冒充原作。

先执行 `node tools/verify-package.js`，随后 `node tools/check.js`。需要压力验证时执行 `node tools/check.js --full`。
所有新增日志写入 `local_reports/`，不要改写随包交付的验收证据。
无需 npm install；Node >=22。游戏端只带纯运行依赖，不导入 `src/index.js`。

必须保留 R1/R2/R3 及新增发布门禁测试。原 35 项测试仍在；旧测试夹具调整原因见接入文档第六节，不准通过删除失败断言“修复”问题。
校验共享的是基础结构契约；独立验解不调用运行内核的取牌、图或消除逻辑。不要为了少写代码破坏这种独立性。

本版是算法子工程可用基线，不是全项目验收完成。移出、撤回、复活、广告/分享、每日额度、存档恢复、排行榜、话题 PK、荣誉、装扮等都还要按原范围继续接入。
从 `docs/reference/` 对照规则来源和已批准技术设计；接口变动以 `docs/接口与接入_v0.8.md` 为准。
生成器仍输出合成模板；不可把 2,000 局测试称为 2,000 种历史地图或原作通关率。

开发工具 HTML 中的答案回放和数字图案不是正式玩家功能；微信联调目录也带测试凭据，不能直接作为正式发布版本。
正式客户端不要携带 generation receipt、seed 或 witness。

每次交付提交：修改文件、最小反例、修复前后测试命令和实际结果、未验收范围。
独立代码审查尚未由第三方/另一个模型完成，不得在交接报告中伪造审查签字。
