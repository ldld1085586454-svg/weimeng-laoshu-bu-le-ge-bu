# 田园主题素材

根据用户选定的 `docs/product/reference-commercial-ui.png`，背景、羊角色和基础组件使用独立生成素材；最新牌面采用用户本次提供的卡通图案，经加工后按 `manifest.json` 语义键接入实际游戏。效果图没有被裁切作为运行界面。

- `home.png`、`board.png`：首页及对局背景。
- `characters.png`：卧姿、欢呼、普通、草帽、围巾、墓碑、三项荣誉。
- `user-cards.png`：用户提供的20个卡通图案，经透明背景处理与边缘整理；当前关卡按确认顺序使用前15个。
- `user-cards-index.json`：全部20个图案的名称及图集矩形，最后5个保留备用。
- `tiles.png`：上一版农场牌面备份，当前清单不再引用。
- `components.png`：叶枝、进度星、牌框。
- `primary.png`：细金色边框的黄色主按钮。
- `fonts/ZCOOLKuaiLe-Regular.ttf`：站酷快乐体，来自 Google Fonts；授权见同目录 `OFL.txt`。

处理后的 PNG 保留完整，运行时通过清单中的 rect 取出各个透明图案；运行时文字、棋盘、点击区域和统计由代码绘制。后续替换方法见 `docs/product/正式素材替换.md`。用户牌面来自本次提供的图片；本说明不为仓库其它历史资料授予新的许可。
