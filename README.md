# 威猛老鼠卜了个卜

本仓库保存当前定位到的完整游戏开发工程。来源：`羊了个羊_全模块开发版_v0.12_美术落位版_v0.7.zip`，包内项目名 `sheep-game-development`，版本 `0.12.0-dev.1`。原工程与界面中的“羊了个羊”名称予以保留；本次上传未修改玩法或品牌资源。

## 获取与运行

- 根目录 `威猛老鼠卜了个卜_开发工程_v0.12_public.zip` 是公开上传时的工程快照；后续开发以当前源码为准。
- 网页主入口：`全模块游戏_双击打开.html`。运行 `npm run build` 可从最新源码重建网页入口与微信开发工程。
- 安装 Node.js 22 或以上后，在仓库目录运行 `npm start`（或 `npm run full:serve`）。启动会先构建，随后在 `http://127.0.0.1:8770` 提供本机开发服务；改源码后重启即可查看更新。Windows 可双击 `启动全模块预览.cmd`。
- 本机服务数据保存在 `local-data/social.json`；验收使用 `npm run full:check`，浏览器验收脚本将新报告写入 `local_reports/product/`。
- 微信开发者工具导入 `wechat_full/`。需自行配置有权限的 AppID；默认使用 simulation 模式，真实广告、分享与原生社交能力默认关闭。
- 更多说明见 `README_先读我.md` 和 `docs/product/`。
